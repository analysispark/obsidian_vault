# Section 04 | 상관과 예측

## 사용목적

- <b><u>변수들간의 관련성</b></u>을 분석하기 위해 사용(모든 변수는 비율, 등간척도)
- 상관관계분석은 한 변수가 다른 변수와 관련성을 가지고 있는지의 여부와 관련성이 있다면 
- 어느 정도 있는지를 알아볼 수 있는 분석

- 예제: 용돈과 지출과의 관계 / 운동시간과 체지방율의 관계 / 키와 앉은키의 관계

### 기본원리

- $$\rho = Cov(X,Y)\,/\,\sigma{x}\cdot\sigma{y}$$
$$
r = \frac{\frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{n-1}}
{\sqrt{\frac{\sum(x_i - \bar{x})^2}{n-1}} \times 
\sqrt{\frac{\sum(y_i - \bar{y})^2}{n-1}}} 
$$

---

(그림)

- 특정변수의 분산 중에서 다른 변수와 같이 변화하는 분산(공분산)이 어느 정도 인가
- 공통으로 변화하는 공분산이 클수록 상관도는 높아짐
- 상관계수는 r로 표시하며 $-1 \leq r \geq +1$  를 갖는다
- 상관관계의 강도를 나타내는것이 상관계수이며, 상관계수의 제곱을 결정계수라 한다
- 결정계수는 설명력을 나타내는데(B)의 예를 통해 보면 소득이 소비액을 설명해 주는 정도는 36% (0.6 * 0.6 = 0.36 = 36%)가 된다

## 기본모형

- $$\rho = Cov(X,Y)\,/\,\sigma{x}\cdot\sigma{y}$$
Where, Cov(X,Y): 변수 X와 Y의 모집단 공분산
		$\sigma_x$ : 변수 X의 모집단 표준편차
		$\sigma_y$ : 변수 Y의 모집단 표준편차
