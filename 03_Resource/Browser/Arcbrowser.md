### 단축키
- Side Bar 열기  
    command + s  

- 캡쳐 기능  
    shift + command + 2  

- 창 닫기  
    command + w

- 새 창 열기  
    command + t

- 탭 변경  
    control + tab

- 창 분할  
    control + shift + =  

- 분할한 창에서 창 선택  
    control + shift + 1 ~ 창 순서에 따른 숫자

- 새 윈도우 생성  
    shift + command + N

- 윈도우 닫기  
    shift + command + W

- 새 창 열기  
    command + N

- 사이드 바 상단에 pin으로 바로 이동  
    command + 1 ~ 지정한 개수만큼

- 개발자 도구  
    option + command + i  

- 뒤로가기, 앞으로 가기  
    command + [  
    command + ]  


- 아크 숨기기  
    command + H  
    진짜 말 그대로 아예 숨겨짐 (Dock에서 ark 누르면 띄워짐)  


- 아크 윈도우 독으로 숨기기  
    command + M  


- 커맨드 바 열기  
    command + L

- View Library 열기  
    shift + command + L  


- 익스텐션 열기  
    command + E  


- 스페이스 옮겨다니기  
    control + 숫자 1 ~
