
## 표의 생성

`|` 기호로 열을 구분하고 줄바꿈으로 행을 구분합니다.  
`|-|-|-|`가 헤더와 데이터를 구분하는 역할을 합니다.  
(없으면 표가 생성되지 않습니다. 안에 들어가는 `-`의 개수는 표시되는 표와 무관합니다.)

```null
|헤더1|헤더2|헤더3|
|------|------|------|
|데이터1|데이터2|데이터3|
|데이터1|데이터2|데이터3|
```

| 헤더1  | 헤더2  | 헤더3  |
| ---- | ---- | ---- |
| 데이터1 | 데이터2 | 데이터3 |
| 데이터1 | 데이터2 | 데이터3 |

---

## 표의 정렬

헤더와 데이터를 구분하는 줄의 각 셀에 `:`(콜론) 문자를 왼쪽 끝에 넣으면 왼쪽 정렬, 양쪽 끝에 넣으면 가운데 정렬, 오른쪽 끝에 넣으면 오른쪽 정렬이 됩니다.

```null
|---헤더1---|---헤더2---|---헤더3---|
|:------|:------:|------:|
|데이터1|데이터2|데이터3|
|데이터1|데이터2|데이터3|
```

|---헤더1---|---헤더2---|---헤더3---|
|:------|:------:|------:|
|데이터1|데이터2|데이터3|
|데이터1|데이터2|데이터3|

## 표의 줄바꿈

표의 셀 내에서 줄 바꿈을 하고 싶다면 \<br> 을 넣어서 사용한다.
Pandoc 표 내부 줄바꿈도 \<br> 을 사용하는 것이 가장 안전하다.
